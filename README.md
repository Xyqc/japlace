# japlace: Modified Pokémon Showdown AI

**japlace** is a heavily modified fork of [**Laplace**](https://github.com/influxtion/Laplace-Pokemon-Showdown-AI) by Jayden Shin, made by **Xyqc**. It runs on a patched [**poke-engine**](https://github.com/pmariglia/poke-engine) backend and adds a learned policy network and further search improvements for Pokémon Showdown. Its architecture and methods are modelled on [**Jaxcalibur**](https://jaxcalibur.github.io/).

Laplace's existing battle AI is combined with:

* Learned policy priors for MCTS
* Item, Ability, and Tera prediction
* Hidden-information posterior sampling
* Battle history features
* PUCT / regret-matching root search
* Optional opponent-action heuristics
* Policy training and self-play data generation
* Built-in A/B benchmarking

The tree is also kept in sync with upstream Laplace (team-preview fixes and the optional adaptive/parallel search have been merged in). The adaptive/parallel search is off by default so the tuned search settings in `ladder.py` are unchanged.

## Setup

Requires Python 3.12, Git and a Rust toolchain.

### Create the virtual environment

```cmd
cd Laplace-Pokemon-Showdown-AI
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install maturin
```

### Build the patched poke-engine

With the virtual environment active:

```cmd
cd ..\poke-engine-main\poke-engine-py
maturin develop --release --no-default-features --features poke-engine/gen9,poke-engine/terastallization
cd ..\..\Laplace-Pokemon-Showdown-AI
```

`--no-default-features` is required. Without it the build fails with duplicate-constant errors.

### Install the AI project

```cmd
pip install -e .
```

Do not install the stock `poke-engine` from PyPI, and do not run `scripts/setup.py`. Either one overwrites the patched engine.

Check that the patched engine is the one in use:

```cmd
python -c "import poke_engine; print(poke_engine.__file__)"
```

The path should point inside `poke-engine-main`, not `site-packages`.

## Generate Training Data

Self-play needs a local Pokémon Showdown server running.

```cmd
python -m laplace.cli.gen_policy_data --battles 500 --workers 10 --det 4 --time-ms 60
```

Training data is written to:

```text
data_policy/
```

## Train the Policy Network

```cmd
python -m laplace.cli.train_policy --epochs 30
```

The trained model is saved as:

```text
models/policy_net.pt
```

## Benchmark

Compare the trained policy against the baseline:

```cmd
python -m laplace.cli.bench_ab --battles 100 --workers 10 --challenger-kwargs "{\"policy_model_path\":\"models/policy_net.pt\"}"
```

## Play on Pokémon Showdown

Put your Showdown login in `.env`, then run:

```cmd
python -m laplace.cli.ladder --format gen9randombattle
```

For Random Battle, the ladder client loads `models/policy_net.pt` automatically once the file exists. The Gen 9 OU ladder (`python -m laplace.cli.ladder_ou --team <name>`) uses the patched engine but not the policy or value networks.
